## OpenWiki

This repository uses OpenWiki as its checked-in knowledge and agent-routing surface. Start with `openwiki/quickstart.md`, then follow its links to specifications, runbooks, references, accepted decisions, research provenance, and drift evidence.

Maintain it generator-first: update the source that owns the claim, run `openwiki code --update --print`, and review the generated diff against source authority. Direct page edits are reserved for explicit curation or correction. No recurring OpenWiki automation is authorized.
